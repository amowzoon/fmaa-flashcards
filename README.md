# FMAA Flashcards (Sections A & B)

Run: `cd fmaa-flashcards && python3 -m http.server 8080` → http://localhost:8080
(or just double-click index.html — no server needed)

Modes: Flashcards (flip/grade) · Learn (adaptive MC, 2 consecutive correct = known) · Write (typed recall, self-grade) · Test (49 real PRC quiz questions w/ explanations) · Browse · Progress.
Progress saved in browser localStorage. Edit deck.js to add cards: ["A1","front","back"].
